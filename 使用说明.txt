风火轮打字 v1.0.0 · 使用说明
========================================

1. 双击「风火轮打字.exe」即可启动（首次启动会解压资源，约 2~4 秒）。
   不需要安装 Python，也不需要管理员权限。

2. 首页选一门课，或点「立即练习」继续上次的课程。
   · 英文：直接敲键盘，目标文字会逐字变色，打错可以退格；
   · 中文：在下方输入框输入高亮的那一行，整行打对会自动换行。

3. 快捷键：Tab / F5 重开本局，Esc 返回首页，F1 打开帮助；
   Ctrl + 加号 / 减号 放大或缩小整个界面，Ctrl + 0 恢复标准。

   设置页顶部「界面缩放」也可以选 紧凑 / 标准 / 大 / 超大。
   练习过程中暂不允许改缩放（会丢进度），退出本局再改即可。

4. 背景音乐：点底部「播放列表」→「添加音乐」或「添加文件夹」，
   支持 mp3 / wav / ogg / flac / m4a / wma；列表会自动记住。
   按键音效在「设置 → 声音 → 按键音效」开启，音量可单独调；
   如果仍然没有声音，请确认系统音量与输出设备正常。

5. 成绩与设置保存在：
   %LOCALAPPDATA%\FirewheelTyping\
   ├── settings.json   设置与音乐列表
   └── history.db      练习记录（SQLite）

6. 本程序为绿色便携版：复制 exe 到任意文件夹都能用；
   删除上述数据文件夹即可恢复出厂状态。

7. 本项目为原创练习作品，界面/代码/语料自行实现；
   与「金山打字通」「哪吒打字」等商业软件无关。
